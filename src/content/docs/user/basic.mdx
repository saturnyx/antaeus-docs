In this example, we will be writing a basic program that which will setup a drivetrain. This guide will assume that you already have a basic [Vexide](https://vexide.dev) up and ready. If not, you can check out [this guide](/intro/prereq).

Initially, you will be greeted with a simple `main.rs` that will look something like this.
```rust
use vexide::prelude::*;

struct Robot {} // Here is where all your robot peripherals will go

impl Compete for Robot {
    async fn autonomous(&mut self) {
        // Autonomous stuff will go here!
        println!("Autonomous!");
    }

    async fn driver(&mut self) {
        // Driver Control or opcontrol will go here.
        println!("Driver!");
    }
}

// This is the main function. It serves as the entrypoint for all you code.
#[vexide::main]
async fn main(peripherals: Peripherals) {
    let robot = Robot {};

    robot.compete().await;
}

// These are tests, we won't really be talking about this for now.
#[cfg(test)]
mod tests {
    #[test]
    fn it_adds_two() {
        assert_eq!(2 + 2, 4);
    }
}
```

Now, this template won't start working all by itself. We need to add in the peripherals. In the next topic, we'll be looking into how to add more peripherals. Before that, I highly recommend you take a look into [vexides's wiki](https://vexide.dev/docs/peripherals/) about peripherals.
